My usage (#726): a signed-in person sees only their own spend, sessions, failures and tool calls under a new My usage button in the top bar, beside My reporters. Whose figures they are comes from the sign-in on the server, so no request can ask for another person's. It is off until an Admin turns on **My usage page** in Admin > Settings, and it covers every harness, with a Harness filter on tool calls and CSV, JSON and Print.
