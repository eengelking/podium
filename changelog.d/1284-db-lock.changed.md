`npm run test:db`, `npm run e2e:fast`, `scripts/e2e-all.sh` and `scripts/e2e-up.sh run` now share one lock per machine and user (`scripts/db-lock.sh`), so only one heavy database job runs at a time and the next one waits its turn and says who it waits for, instead of two runs overlapping and failing timing-sensitive tests. A lock whose holder is gone is taken over, CI takes no lock, and `PODIUM_DB_LOCK=off` skips it.
