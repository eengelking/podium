**`npm run test:all` runs every test suite from one command, with one database lock and one result line (#1295).** It runs the server suite on every adapter (`test:db`), the frontend tests, `test:core`, each harness's `test:mod:<harness>` and `typecheck:mod:<harness>` (found from `package.json`) and `e2e:fast`, one after another, and ends with one `TEST ALL RESULT:` line with each suite's counts. It takes `--suite`, `--db`, `--shards`, `--out`, `--fail-fast` and arguments after `--` for one suite. A suite that cannot run on the machine is NOT RUN with the reason, and a narrowed or incomplete run says LIMITED and is not a pass for a pull request or a release. Tooling only; no app change.
