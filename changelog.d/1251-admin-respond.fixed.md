An Admin now needs the owner's allow to send to a person's session, run `/clear` or `/compact` on it, or answer its question, plan or tool prompt (#1251). The owner gives it per reporter with the new Admin may respond column in Your reporters on My reporters, and it is off by default. Without it the Admin can still read a waiting ask, as before, and the owner is told; the answer controls and the message box give way to a note that says why, and a refused try is written to the Admin log and told to the owner in the console and in their reporter. A session owned by Admin or by no one is unchanged.
