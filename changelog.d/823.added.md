**MariaDB as a third database (#823).** `PODIUM_DB=mariadb://user:password@host:3306/dbname` keeps Podium's data in MariaDB 11.x (tested on 11.4), beside SQLite (the default) and PostgreSQL 17. Those are the supported databases: SQLite (built in), PostgreSQL 17 and MariaDB 11.x (tested on 11.4); other versions of PostgreSQL and MariaDB are untested. The database must exist (`CHARACTER SET utf8mb4`); Podium makes its tables in it, the Activity history and recordings included, and sets every text column to `utf8mb4_nopad_bin`, so names compare byte for byte as on SQLite and emoji are kept. The only URL parameter is `ssl=true` or `ssl=false`. One server per database: a named lock refuses a second one, and a lost lock stops the server. Each step of a schema upgrade can be run again, since MariaDB commits DDL on its own. Keys and indexed text have length limits (an id 255 characters, a reporter key 383), and a longer value is an error. The log, `/health` and `podiumctl config` show `host:port/dbname`, never the user or the password. MySQL is not supported, and nothing is copied from a SQLite or PostgreSQL database. CI runs every test on MariaDB 11.4, and the end-to-end suite runs on 11.4.13. `docs/SERVER.md` ("Using MariaDB") has the privileges, the limits and what has not been tested.
