An agent in a Direct Message with several members can answer in it. Before, the hint told it to answer with `podium_send` to `person:<name>`, and Podium refused that with "You cannot see an orchestrator called person:<name>", because a message written in such a conversation is not stored where that address looks. The message an agent is handed now carries the conversation's id, the hint says to answer to `convo:<id>`, and the answer is posted in the conversation as the agent's, for everyone in it, only where a person wrote to it in the last hour. Claude Code and OpenCode share the address, the hint and the answer (#1299).
