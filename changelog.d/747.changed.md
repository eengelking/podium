The console's own files are now served compressed and cacheable. The script, the stylesheet and the page are gzipped for a browser that accepts it (the script goes from about 900 KB to 255 KB, the stylesheet from 159 KB to 28 KB), a file under `/assets/` is cached for a year and marked `immutable` (the build names each of them by its content hash), and `index.html` is revalidated on every visit, so a repeat visit should fetch the page and not the assets. `PODIUM_COMPRESSION=off` turns the gzip off, as it does for `/api/fleet/state`. The event stream is still not compressed (#747).
