In a Direct Message with an agent in it, `@` addresses one member, so a message goes only to that agent or person (#1282). The `@` list offers only the members of the conversation, a message with no `@` still goes to every agent, and under each message a line says who it was for and the delivery line names only the agents it was handed to. A name that is not in the conversation, `@group` and `@everyone` are refused in words and nothing is sent. Who a message was for is kept in the new `conversation_deliveries` table in every adapter.
