Text an agent sends to another agent or to a person through `podium_send` is now scrubbed on the server the way Chat text is: Podium's own credentials (the admin secret, a person's token) and the common secret shapes are replaced with `[redacted]` before the length is judged and before any database stores it, whichever reporter sent it. Before this, only the reporter redacted, and it cannot know Podium's own credentials. A clean message is stored as it was. When the server replaced something, `podium_send` says how many values it replaced, in a sentence apart from the reporter's own count (#1329).
