The Activity modal has a Background tab beside Output. It lists the background shells and monitors that one orchestrator, subagent or fork started, with each one's state, run time and last output, and, with the new `backgroundOutput` reporter option and the Admin's Background shell output switch on, its whole command and what it printed. A shell with no output for 5 minutes reads "Quiet". Both Claude Code and OpenCode report them; OpenCode has no monitors (#897).
