Chat no longer reads every direct message to answer a thread, a send, the Admin's keep-alive ping, the Admin picker's conversation counts or a session leaving with held messages. The store gained one query for a conversation by its pair, one grouped count for every person, and one for held mentions in a channel, in SQLite, PostgreSQL and MariaDB, so these paths no longer slow down as the history grows. What Chat shows is unchanged, except that a held mention further back than the newest 1,000 channel messages is now found too (#1046).
