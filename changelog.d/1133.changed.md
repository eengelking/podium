**Every report table can be sorted by its column headings (#1133).** On Admin > Reporting (Usage, Spend, Sessions, Tools, Failures and the rest) and on My usage, a heading is now a button. A number column shows the largest first, the period and text columns start with the oldest and A to Z, and a second click reverses it. The sort covers every row of the period, then the page is cut from it, and a new sort returns to the first page. The Whole period row stays at the bottom, and a new period or filter starts in the order the server sent.
