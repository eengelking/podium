Redaction no longer takes the character after a secret value with it. Sending `` `password=abc123` `` in Chat now shows `` `password=[redacted]` `` and not `` `password=[redacted] ``: a closing backtick, or a full stop, `!`, `?` or `:` that ends the sentence, stays in the text. Chat, the server's log and the recordings all use the same redactor, so all three are fixed. Text stored before this fix stays as it was stored (#1271).
