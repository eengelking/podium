**`npm run test:db` runs the server suite on every storage adapter, and replaces `scripts/test-db.sh` (#1294).** It takes `--db "KIND [KIND...]"`, `--scope adapters|all`, `--shards N`, `--out DIR`, `--image KIND=REF` and vitest arguments after `--`, like `npm run e2e:fast`, and ends with one `DB TEST RESULT:` line (`sqlite=PASS postgres=PASS mariadb=PASS`) with each database's files and tests. A run that leaves a database out says LIMITED and what was NOT RUN, and is not a pass for a pull request. The container, lock and cleanup behavior is unchanged (`scripts/db-servers.sh`), and `npm test` and CI are unchanged. Tooling only; no app change.
