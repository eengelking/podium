The E2E workflow runs the suite with `scripts/e2e-all.sh --shards 3`, one database at a time, so the release PR's run finishes in a fraction of the 67 minutes it took serially. The `shards` and `databases_at_once` inputs (or the `E2E_SHARDS` and `E2E_DATABASES_AT_ONCE` variables) set how far it goes, and a failure names its database and shard.
