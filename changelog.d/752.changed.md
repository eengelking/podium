A session with many agents now sends its report less often while only counters move. A report over 32 KB that differs from the last one only in tokens, cost, context and call counts waits up to 5 s, so a busy 200-agent session posts about 1.9 MB a minute instead of 8.6 MB, and a counter on the wall can be up to 5 s old. A status, a question, a failure, a plan, a new agent or the end of the session is still sent at once, and the report format is the same (#752).
