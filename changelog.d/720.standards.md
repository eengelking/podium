A new part for a table row that belongs to a row above it, such as the tools under an MCP server on Admin > Reporting > Tools: `tr.mtool`, indented, on the raised surface, shown only while its parent row's `rowbtn` is open (`aria-expanded`), with the existing `rowbtn`, a chevron that turns when open and `srvnote`, the quieter words after the server's name ("MCP server, 3 tools").
