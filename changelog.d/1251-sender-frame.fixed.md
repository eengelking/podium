Every message from Podium now reaches the model in one frame in Claude Code and in OpenCode (#1251): who sent it (the owner from Chat or the console, an Administrator the owner allowed, or the author of a channel `@`), the text quoted line by line, and a closing line, so a line inside the text cannot pass as Podium's own. Claude Code used to submit the owner's message as bare text, and OpenCode prefixed an unquoted label. A reporter that gets a message from an older server keeps the text as it was.
