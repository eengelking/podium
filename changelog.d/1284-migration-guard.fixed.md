The upgrade that binds sessions, reporters, peer messages and daily spend to a person's id no longer hands a deleted person's rows to a new person who took the same name: a row is given only to a person who existed when it was written. The upgrade of a person's end of a link and of Chat threads also runs once and reads an all-digit name the same way in both, so a person called "42" is never taken for the person with id 42, and a restart after a crash cannot turn `person:5` into `person:gone:5`.
