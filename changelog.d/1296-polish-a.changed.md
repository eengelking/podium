Orchestrator messaging is faster with many agents and machines, and the test scripts no longer fill the disk: `podium_peers` and `podium_send` read the reporters and the sender's rights once for all of an owner's agents, so a list costs 7 database statements whether the owner has 5 agents or 30 (it cost 68 and 318), with the same answer. An owner's defaults are keyed by the person's id alone, which drops a name key and an index that stored the id twice more; the database upgrades on its own (SQLite migration 61, PostgreSQL and MariaDB step 36), a row with no person is dropped, and the step takes milliseconds. `npm run test:db` and `npm run e2e:fast` now remove their database containers with their data volumes, where each run left one behind (#1296)
