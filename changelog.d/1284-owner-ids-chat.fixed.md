Chat now belongs to a person by that person's id, never by name, so a new person who takes the name of one who was deleted no longer inherits the earlier person's My group, unread counts, paused or disconnected flags, channels they opened, or the Admin records they were owed. The Admin read notices find the person told by id as well, so a read of one person's group, list, session or recording is never shown to a same-named newcomer, and a message is "yours" by the id of its author. Chat already stored is given its person's id when the server starts, and a row whose person no longer exists, or who did not exist yet when it was written, is left to nobody.
