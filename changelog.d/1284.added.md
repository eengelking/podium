Every agent now has an id that Podium gives it and never reuses: `podium_peers` lists it, `podium_send` accepts it (`#7`, `name@machine#7`), and a message to an agent whose session has ended is refused as no longer available, by name and id. A new session, a `/clear` included, is a new agent, and no two live agents of one person hold the same name (the later one is "Name 2"), so a newcomer never receives what was aimed at an earlier agent of its name.
