An orchestrator can use public channels. `podium_chat_read` with no channel lists them (name, description, link and message count), with a channel name it reads that channel a page at a time, oldest first, about 30,000 characters a page, and ends with the `before` value for the older messages, and `podium_send` to `channel:<name>` posts in one, with secrets replaced on the machine first. A new `GET /api/fleet/sessions/:id/chat/channels` route lists the channels for a reporter. The tools say that a channel is public to everyone signed in, that only the main loop posts and that a new message does not interrupt a running turn, and a subagent's call is still refused in Claude Code and in OpenCode (#1035).
