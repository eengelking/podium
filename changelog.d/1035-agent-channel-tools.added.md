An orchestrator can use public channels the way it uses General. `podium_chat_read` with no channel lists the channels (name, description, link and message count, never a message, and with no call-in needed), and with a channel name it reads that channel, and `podium_send` to `channel:<name>` posts in it, with secrets replaced on the machine first. In every channel, General, My group and a public one alike, an orchestrator reads or posts only when an `@` called it into that channel in the last hour, and it sees only that last hour, the newest messages that fit in about 30,000 characters, with a `before` value for older ones still inside the hour; otherwise Podium refuses with "You were not called into this channel in the last hour." A new `GET /api/fleet/sessions/:id/chat/channels` route lists the channels for a reporter. The tools say that a channel is public to everyone signed in, that only the main loop posts and that a new message does not interrupt a running turn, and a subagent's call is still refused in Claude Code and in OpenCode (#1035).
