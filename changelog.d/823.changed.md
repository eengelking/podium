**The test tooling covers every database, from one table (#823).** `scripts/test-db.sh` replaces `scripts/test-pg.sh`: it starts a throwaway container for every adapter that needs a database server (PostgreSQL and MariaDB), all at once, sets each one's test server variable (`PODIUM_TEST_PG`, `PODIUM_TEST_MARIADB`) and runs the server suite, each database on the one version tested (PostgreSQL 17, MariaDB 11.4). The databases, their images, variables and reset commands are one table, `scripts/db-adapters.mjs`, which `scripts/e2e-up.sh` also reads, so `E2E_DB=mariadb` runs the end-to-end suite on MariaDB (`E2E_MARIADB_IMAGE`, default the pinned `mariadb:11.4.13`), and the `E2E` workflow's default list is `sqlite postgres mariadb`. `scripts/throwaway-db.mjs`, the order-parity check and the smoke, soak, perf and peers scripts take a `mariadb://` server too. CI has one new check, `Test with MariaDB 11.4`. Tooling only; no app change.
