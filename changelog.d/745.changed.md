`GET /api/fleet/state` is now gzipped for a client that sends `Accept-Encoding: gzip`, which takes the large fleet's 1.39 MB to about 171 KB, so first paint and a resync are faster over a slow link. A client that sends no `Accept-Encoding` (the health check, `podiumctl`, the scripts) still gets plain JSON, and `PODIUM_COMPRESSION=off` turns it off. The event stream is not compressed: a compressor per client cost too much CPU and memory at 100 clients (#745).
