The upgrade that binds a person's data to their id no longer hands a deleted person's messaging defaults or link ends to a new person who took the same name. A person's own end of a link is rewritten to their id only for a row written after they were made, and an older row stays under a key no person's equals. The defaults, which have no time to check, are kept only for a person who owns data written since they were made and has none from before; every other person starts from the server's defaults. A person whose name begins `gone:` is now read as a person, never as a key already rewritten.
