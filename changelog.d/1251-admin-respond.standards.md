A consent switch for what an Admin may do with an owner's reporters is a column in Your reporters on My reporters: Admin may respond, a `.sw` in each row, off by default, centered under its heading with the new `.c` cell class beside `.n`. An Admin without it still opens the Respond window to read an ask, which shows the ask read-only and one note in place of the answer controls and the message box. Approved on the mockup for #1251 (mockup/podium-admin-respond-allow.html).
