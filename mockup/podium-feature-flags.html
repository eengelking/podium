Feature flag for the activity feed

Admin > Settings gets a Feature flags section. The activity feed is its first flag, on by default. Turning it off stops the feature for everyone on this server: the console no longer fetches or shows activity, the server asks no mod for it and forgets what it held. The reporter option stays what it is: a machine still sends nothing until its own activityFeed option is on, so the feed needs both. The panel on the right changes as you flip the switch; the third state shows what it looks like when the flag is on but the reporter option is not.
