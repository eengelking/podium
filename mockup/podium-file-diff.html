File diff modal

Issue #319. A row in the Files list becomes a button that opens the shared modal with that file’s diff. It needs the reporter’s fileDiff option, the Admin’s file-diff flag, and the session’s signed-in owner. Only the owner can open it: not an Admin, and not anyone else. Every state below is a frame of the same modal.

The Files list

With everything on and the session’s signed-in owner, each row is a button named “Open diff of <path>”. Enter, Space and a click open it. The row gains a hover state and the standard focus ring; nothing else about it changes.

The line varies: “Sign in to open diffs.” (signed out), “Only Dana can open diffs.” (someone else’s session, an Admin included), “Turn on the file diff to open this.” (a switch is off; it names Admin > Settings for the flag and the fileDiff option for the machine).

The modal

The modal is wider than the others (up to 1240px) so the old file sits on the left and the new one on the right, level line for line. A removed line has a filler beside it on the right, and an added line has one on the left. The title is the path, the sub line is the status letter, the counts and the base. A footer says what was cut. It closes with the X, Esc or the dimmed area, and focus returns to the row. Removed and added lines carry a − or + mark as well as a tint. Each side scrolls sideways on its own and the other follows. Below 720px wide there is room for only one side, so the same lines show in a single column with both line numbers.

Rules the frames follow

Side by side where there is room, one column where there is not. Anything that looks like a secret is replaced with [redacted] on the session’s machine, before it is sent, in removed lines as well as added ones. Every line is a text node, never markup. Meaning never rests on color alone. Long lines scroll inside the modal and never widen the page. The diff is against the same base the Files list counts from, so the row’s numbers equal the lines here. Nothing is kept: closing the modal clears it, and opening it again asks again.
