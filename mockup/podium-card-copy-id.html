Mockup #759 - Copy session id Theme

Copy session id, beside the card instead of inside it

Today the id on every wall card is a span role="button" inside the card's own button: a control inside a control (axe nested-interactive), about 19 px tall (target-size), and named "Copy session id 3f9a1c2e" while it reads "Copied" after a click. The cards below use the app's own markup. The id looks the same, but it is now a real button next to the card's button, where the pin already sits. Clicking the card still opens the orchestrator; clicking the id only copies.

The control, in each state

Idle. Same text, icon and muted color as today.

Hover. Same hover fill and border as today.

Keyboard focus. The standard focus ring (--sonnet, 2 px). Now a stop of its own in the tab order, right after the card button and before the pin.

Copied for 1.6 s, with the check icon. "Copy failed" has the same shape.

Hit area (dashed outline)

The button is at least 24 by 24 px; it is about 60 by 24 here. The path row grows about 5 px (19 to 24) so the card is that much taller. Nothing else on the card moves.

Click an id to copy it; click anywhere else on a card to open it.

One column, the same cards. A long path is cut with an ellipsis before the id, as today.

Decisions this mockup proposes

A sibling, not a childThe id is a button in .card-slot after the card button, like pin, Remove and Respond. Its click needs no stopPropagation, and the keyboard handler goes away.
Name contains the textIdle: visible "3f9a1c2e", name "Copy session id 3f9a1c2e". While it reads "Copied" or "Copy failed" the name is that text, so a voice user can say what they see (2.5.3). The live region keeps announcing the result.
One component, one lookThe orchestrator page keeps its own id cell (#352); only the card's copy is sibling-placed. The orchestrator button is untouched.
StandardsNo token, no new color. The control keeps the existing .sid class, so no new component. If the maintainer wants the 24 px minimum written into a standard, that is a Standards: line.
