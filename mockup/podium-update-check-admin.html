The wall

Why it is a feature flag, and the one rule it bends

Release check turns off a behavior of the server (a request to GitHub once a day), which is what Feature flags are for: "Turn a feature off for everyone on this server". Off, the server makes no request at all, and a notice already showing leaves the wall.

The wall-notice rules say every notice has its switch in Wall notices. This notice's X does not turn it off for good: it hides the release it names, and a newer release shows it again. So the switch that stops the notice for good is the flag. If you would rather every notice be listed under Wall notices, the demo bar's "Also its own switch" shows the option: a second row there that hides the notice but keeps checking.
