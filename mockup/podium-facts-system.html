Machine and System in the facts grid

#427 puts the machine a session runs on, and its OS and version such as Fedora Linux 44 or macOS 15.4, in the orchestrator facts grid. The grid becomes twelve cells in two rows of six, and two columns by six rows at 640 px and narrower. Row one is Agents, Est. cost, Tokens, Running for, Agent time and Blowouts. Row two is Machine, System, Reporter, Session, Resume and Fork. Blowouts moves from the start of row two to the end of row one to make room.

  • Machine is the host name the reporter sends with its session, in the mono face like the Reporter's version.
  • System has the family's icon (a laptop for macOS, a terminal for Linux, a window for Windows, as on My reporters) and the text as the reporter sent it. Long text is cut with an ellipsis, and the popup holds the whole text.
  • Popup: the one Resume and Fork already have. It opens above the cell on hover and on keyboard focus, closes on Escape, holds text only, and opens below the cell when the page has no room above it. In the two-column layout a popup in the left column opens to the right, so it stays on the page.
  • Not reported: the muted words, as My reporters shows them, never blank or "undefined". The popup says why. An older reporter, or a command that failed, points at updating podium-reporter. A session with no user name (settings hooks, a reporter with no userName, and so every session in the Admin and Unassigned bands) sends no machine at all, so both cells read "Not reported" and the popup points at setting a user name instead.
  • History's page: the same two cells from the stored session.
