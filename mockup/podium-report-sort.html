What changes

  • Every column heading of a report table becomes a button, the same .thbtn that Admin > Reporters uses. That is one change in the shared report table, so Admin > Reporting (Usage, Spend, Sessions, Tools, Failures and the rest) and My usage get it together.
  • The sorted column shows an arrow and carries aria-sort. The first view is the order the server sends: Period, newest first, so Period shows a down arrow.
  • The sort covers all rows of the period, then paging applies. Changing the sort returns to page 1. The Whole period / Total row is not a row and never moves.
  • Sorting is in the page and is not stored; a reload goes back to newest first.

Decisions for the maintainer

  • First click direction. Admin > Reporters sorts every column ascending first. Here a number column sorts largest first (the question in the issue is "which day had the most"), and Period and text columns sort ascending first (oldest, A to Z). Reporters would keep its own behavior. Same everywhere is possible but makes "most sessions" a two-click answer.
  • Unsorted headers show no arrow, as in Reporters: the pointer and the hover color are the only hint. A faint arrow on every header would be a new variant of the header button and so a standards change; it is not drawn here.
  • Moving the arrow in and out makes a right-aligned heading shift by one arrow's width. Reporters does the same today.
