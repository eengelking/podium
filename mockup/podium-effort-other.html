An effort that is not one of Claude Code's five levels

A v2 report can send any text as effort, such as minimal. Today that reads "Effort not reported". It would read "Effort: minimal", drawn as five hollow bars. null stays the dimmed filled bars and "Effort not reported", and the five levels look as they do now.

Sorting the effort column

Ascending: no effort, then low, medium, high, xhigh, max, then any other text after max, ordered by that text (minimal before ultra). Descending is the exact reverse. Today an unknown value sorts with no effort.

Standards

Tokens only: --muted for the outline, --axis and --eff-* as now. It adds one variant to the effort meter (eff-other), so it is a standards change that needs the maintainer's approval before a Standards: line is written.
