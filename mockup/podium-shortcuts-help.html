A help link on the Shortcuts switch

The Display settings row has a Shortcuts switch (#636). A person who turns it on has to find the keys from a hover hint. With Shortcuts On, the word Shortcuts becomes a link that opens one list of every keyboard shortcut. Off, it stays a plain label, as it is today. Try it: press the switch, then the word. Esc, the X and a click outside close the list, and focus returns to the word.

What is new, and what it reuses

Reused: the Display settings row, the .field and the Admin switch (.sw), and the console's Modal (title, subtitle, X, Esc and click-outside close, focus moves in and returns to what opened it). The inline key chip is the same code style the modal body already uses. No new color: the underline is --muted, hover is --ink, the pipe and the stacked rule are --border.

New: .kbd-link, a dotted word that is a button, and .kbd-cols, two columns split by a pipe. The dotted underline already means "a help term" (cursor: help, .adminv .tt); here it marks a word that does something when pressed. That changes what dotted means, so the maintainer approves it first, and a Standards: line says what dotted means for a help term and for an action.

One list: a single array of shortcuts feeds this modal and the switch's hint (SHORTCUTS_HINT), so the two cannot disagree.
