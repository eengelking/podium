What this mockup proposes

  • A Tools page in the Reporting group, built like the other report pages: Period and filters, the "based on" line, a summary, one neutral-ink chart, tables, the pager, and CSV / JSON / Print.
  • All harnesses. Figures cover every harness that reports (Claude Code and OpenCode today, any added later). A Harness filter narrows them. The tool table shows one column per harness beside the total, and the exports carry a harness column. The version table compares each harness with its own newest version only.
  • MCP servers are a row with their total and a chevron button; opening it shows the server's tools, indented, adding up to the server row.
  • Calls per session is a median and a 90th percentile, per period and for the whole period by harness, not only an average.
  • Partial history shows the existing "Podium has no history before ..." line and never draws zeros for the missing days.
  • Only tool names and counts are stored; the page says so under the chart heading.
  • Not new: the colors, fonts, table, segmented control, pager, summary figures and the rowbtn all exist already. The one small addition is the indented sub-row of an opened MCP server (.mtool), to be added to the standards if the maintainer accepts the page.
