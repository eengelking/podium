What changes

  • One row height. A group label, a page and a part use the same size (13.5 px). Today a group label is 18 px and a page is 15 px, so a group looks like a heading and a page like a footnote.
  • Weight and color say what a row is. A section of the docs (Reference) is bold, a topic or a part with pages inside (Specification, 7. The server) is semibold in the main ink, a page is regular in the secondary ink, and the current page keeps the blue bar and tint it has now. The caret on the right marks every group.
  • Shorter group labels. A folder's README can set sidebar_label in its frontmatter: "5. The mod API", "6. Reporter protocol", "7. The server", "8. The UI". The page keeps its full title. A row that still wraps hangs under its first line.
  • Same rail, same accent. The thin rail per level and the blue current-page bar stay as they are. No new color and no new component; this changes only the sidebar rules in site/src/styles/theme.css and one optional frontmatter field.
  • Narrow width. At 400 px the sidebar opens in place of the page, as in the accepted site mockup, with the same rows.
