Admin > Reporters, one reporter's detail: work-mac reports with the admin secret.

This reporter is using the admin secret

work-mac reports with the admin secret instead of a token made for one person. Its 3 sessions belong to no one, and anyone who holds that secret can report as anyone.

To fix it:

  1. In Admin > People, make a person for whoever runs this reporter, and copy their token.
  2. On work-mac, open the reporter's options. In Claude Code, run /plugin configure podium-reporter@eengelking-marketplace. In the Claude desktop app, open Settings > Plugins > Podium-Reporter > Settings.
  3. Enter that token as token and the person's name as userName.
  1. In Admin > People, make a person for whoever runs this reporter, and copy their token.
  2. On work-mac, open ~/.podium/config.env and set PODIUM_TOKEN to that token and PODIUM_USER to the person's name.
  3. Run opencode service restart, so OpenCode loads the new settings.
