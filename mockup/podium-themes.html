Behavior notes

System mode follows the OS and updates live when it changes. A theme without a palette for the chosen mode falls back to Podium's palette for that mode, and the dropdown marks it ("Dracula, dark only"). Status stays green, amber, orange and red with an icon and a word, never color alone. Credits (name, author, source, license) live in docs/THIRD_PARTY_NOTICES.md and are linked from the dropdown's help line.
