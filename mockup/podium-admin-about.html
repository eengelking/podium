Running as says container or stand-alone. Engine version is the database's own (SQLite or PostgreSQL, whichever adapter is in use). Nothing is collected from a reporter's machine.
  • Copy details: one default button at the right of the page header, where a report puts Export. It is not the primary button: the page has no action that finishes it. It copies everything on the page as plain text for a bug report or a chat (below). It follows the app's copy pattern: the label reads Copied with a check for 1.6 seconds, and nothing changes if the clipboard refuses. Click it to see.
