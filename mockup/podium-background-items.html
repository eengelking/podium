Activity

Silverbolt · orchestrator · Opus 5.5

What is proposed

  • A second tab in the Activity modal, beside Activity, built from the tab control the Board and the Plan / Files fold already use. Its count is the items still running plus finished ones the reporter still holds. The Activity tab does not change.
  • Each item says, without opening it: what it is (Shell, Monitor), its command cut to one line, its state (shape, word, color), who owns it, when it started, how long it has run, and how long ago it last printed. A shell quiet for 5 minutes or more reads "Quiet for 12 min", in the warning color with an icon.
  • Opening an item shows the whole command (redacted, cut at the stated limit) and the newest output, each with Copy, as #431's rows do. Output follows its own reporter option and Admin flag, both off by default.
  • Owner is named on every item with the name the console already uses for that agent. A filter above the list narrows to one owner. If the owner has finished and the item has not, the item says "Owner finished, still running".
  • Live: state, run time, last-output age and output update on the stream while a viewer has the modal open. The preview shows them ticking only in this note, not in the page.

Admin reading someone's items

  • A command and its output are the person's own content, so an Admin's view of them shows the existing red notice (.ch-nav.ro.crit) at the top of the tab, naming the Admin, and the person gets the same notice in the console and a callout in podium-reporter. The record line never holds text. See the "Admin reading" screen.
