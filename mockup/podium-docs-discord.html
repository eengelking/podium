When something is wrong

What to check when a session does not show up, or the console says offline.

The console says offline

Open the console at the address the server printed and check that the mod's server URL names the same host. A config issued while the console was opened as localhost will not reach another machine.

A session does not show up

Check the token, then the reporter's status line. It says whether it is connected and why not.

Still stuck, or want to see how others run Podium? Ask in the Discord. Bugs go to GitHub Issues.

What changes, and why

  • Homepage hero: "Join the Discord" is a third, secondary button. "Get started" stays the only primary button in the hero, and a one-line "Stuck on setup?" link sits under the buttons for the reader who has not decided yet.
  • Homepage, "Join the community": a new section after the install steps, where a reader who just tried to install is most likely to need help. It says what the server is for in three plain lines (ask, show, hear first), and says where bugs and security reports go instead, so Discord does not become the place for filing work. Its button is the primary button of that section. It makes no claim about how many people are there.
  • Top bar: a "Discord" link beside "GitHub", with the same chip shape and a chat icon. It is hidden at narrow width like the rest of the bar's links; the page strip below and the footer carry it there.
  • Every docs page: a short strip at the end of the page, above the footer. It is where a reader who did not find the answer ends up. It reuses the wall's left-accent shape and no new color. It is the page's only Discord button, and it is secondary.
  • Footer: a "Discord" link first in the list.
  • Source of the link: one constant in site/src/components/siteMeta.ts, so a changed invite is one edit.
  • Not done on purpose: no Discord brand color, no logo, no live member count or widget (that needs the server's widget on and a third-party request from every visitor), no pop-up or banner.

Standards used

  • Tokens only, from tokens.css; no root-level token block; light and dark; 400 px frame uses container queries as podium-docs-site.html does.
  • Buttons: ink-fill primary and the plain secondary from the site mockup. Links and buttons are real elements with a visible focus ring; the icon is decorative (aria-hidden) and the header link has a name that says it opens Discord.
  • Copy: a button says what happens ("Join the Discord"); one name for the thing; sentence case.
