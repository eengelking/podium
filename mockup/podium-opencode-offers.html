The message box offers only what the session's reporter can do

OpenCode sessions are offered /clear, which the OpenCode reporter refuses, and a "reply instead" on a question, which it cannot take. The messaging hint for OpenCode names a variable that does nothing. #968 makes the console stop offering these (#858: the console hides what does not work).

What changes. The command list follows the commands a session declares (#940); a session that declares none lists both, so Claude Code looks as before. On an OpenCode question the box shows a one-line note in the existing warnline style, disables Send, and changes the placeholder. The OpenCode messaging hint says the reporter does not message yet. A permission still takes a reply: OpenCode rejects it with the text.

Not new: no class, token or component. The note uses .compose .warnline and .compose .err. No standard changes, so no Standards: line.

Each frame is this file, in light, in dark, and at 400 px. There is no chart in this change, so the dataviz skill has nothing to apply to.
