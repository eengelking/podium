Step 2 of the callout (ReportersTab.tsx). It sets token and userName, which are options like peers, so it needs both routes too. Step 3 already works for either.

To fix it:

  1. In Admin > People, make a person for whoever runs this reporter, and copy their token.
  2. In Claude Code on win-lab, run /plugin configure podium-reporter.
  3. Enter that token as token and the person's name as userName.

Proposed

This reporter is using the admin secret

To fix it:

  1. In Admin > People, make a person for whoever runs this reporter, and copy their token.
  2. On win-lab, open the reporter's options. In Claude Code, run /plugin configure podium-reporter@eengelking-marketplace. In the Claude desktop app, open Settings > Plugins > Podium-Reporter > Settings.
  3. Enter that token as token and the person's name as userName.
