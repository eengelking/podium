                      What this changes

                      • Click a row to open it, click again to close it. Every row starts closed. Anywhere on a row that has more to show is the target: the time, the icon, the line and the empty space beside it. Only a Bash row has this: the mod sends the whole command and the output for Bash and for no other tool, so a Read or Grep row stays as it is today, even when its line was cut at 300 characters. The chevron turns, the row takes the raised surface while open, and the opened part ends with a Collapse button, so there is always a visible way back. Opened, it shows the whole command, then the output with its exit status. Closed, it goes back to the one-line summary it is today. Clicking inside the opened command or output does not close the row, so text can be selected and copied.
                      • Which rows open. A Bash row opens when it has more to show: a cut command, or output. A short Read or Grep row that was not cut has nothing more and stays plain text, with no chevron. Opening a row never scrolls the list away from where the person is reading, and a list that is following the newest row keeps following it.
                      • Keyboard and screen readers. Under the whole-row click, the line is a real button with aria-expanded and aria-controls. Its name is the tool and the line, and it adds the size ("whole command, 1,842 characters") for a screen reader. Enter and Space toggle it.
                      • Failed, code unknown. When Claude Code reports a failure without a code, the row shows the cross and the single word "Failed", with no number.
                      • Output was not collected. Output is gathered only while the panel is open, so a Bash call that finished earlier shows its command and "Output was not collected. Output is only collected while this panel is open." A call still running says it is running.
                      • Exit status. A command that succeeded shows only a check in the good color; a screen reader hears "Succeeded, exit 0" and the check has a "Succeeded" tooltip. Any other exit shows a cross, the words "Exit 2, failed" and the critical color, so a failure is never missed.
                      • Redaction. Secrets the mod redacted show as the existing red [redacted] mark, in the command and in the output. Everything from a session is a text node, never HTML. ANSI color codes are stripped.
                      • Cut-off is said in words. A command or output cut at the limit ends with "[cut off at 20,000 characters]". Nothing is cut silently.
                      • Copy command and Copy output copy the text exactly as shown (redacted), and the button shows Copied with a check for 1.6 seconds, as the copy pattern says.
                      • Replay. The replay's tool call row follows the same pattern. For a Bash call it replaces the "Whole input" and "Result" disclosures with this one row, so a call, its whole command and its output open together. Other tools keep today's disclosure.
                      • The state of open rows survives the refresh. Rows are keyed by entry, not position, so the 5 to 60 s refresh does not close what a person opened. An entry that scrolls out of the newest 20 goes with the open state.
                      • Everything on this page uses the app's classes and tokens. The new pieces are named in the stylesheet comment above and are proposed for the standards by a Standards: line, with the replay's classes from #353 that are not on docs/standards/ yet.

                      Checked against the standards

                      • Colors are tokens only (no hex or rgb in this file, no :root block). Status is a shape and a color, and a failure adds its words; a success has its word for screen readers and a tooltip (the maintainer chose a bare check for success). A note about something cut or missing is plain text in the ink color. Text from a session is a text node. The page does not scroll sideways at 400 px; the command and output wrap, so nothing scrolls sideways.
                      • Not covered by the standards, proposed here: a whole feed row as a disclosure button; Copy as a small labelled button (the standard's copy control is a whole-cell value); a cross for a failed exit (a check already means done). The chevron reuses the Blowouts cell's .chev idea. The failure box is not reused because a failed call's output opens inside its own row; say if you would rather a failed row open as the failure box.
                      • This page has no chart, so the data-visualization rules apply only to status: exit status is never color alone.
