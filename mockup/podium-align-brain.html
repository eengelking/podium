Projects and sharing

A memory belongs to a project, and is personal (only you) or shared (that project's members). Global memories are your own preferences. Nothing crosses from one project to another.

Life of a memory

Every delete is kept for 30 days and can be restored by the owner. An Admin cannot restore one.

Sync with local memory files

For each memory in a mirrored folder, the sync compares the local file and the server with the version both last agreed on (the base). Nothing is chosen silently when both changed.

Guards that apply to every sync

GuardWhat it does
Missing folderA missing or unreadable folder is not a deleted folder. The sync does nothing and says why
Mass changeMore than 20 local files written or deleted, or more than 3 memories trashed, stops and asks. More than 10 trashed in 24 hours also pauses

An Admin never reads in silence

The project rule, applied to memories: whenever an Admin sees a person's non-public content, the person is told in the console and in the reporter.

Search and weight

Search runs from an index inside the server process. It never decides access: every page is re-checked through the storage layer.

How weight rises and falls

Uses and votes each add an amount that halves every 90 days (the amounts are Admin settings: use +1, upvote +3, "not relevant" -1, and wrong, outdated or unsafe -4). A use is a person's agent opening a memory, counted once per person, memory and day. A search result alone is not a use. Weight multiplies the relevance score by at most half either way, so it orders results and never hides one.

Withdrawing a vote

A changed or withdrawn vote takes back what is left of it, not what it was. An upvote of +3 given at day 0 has +1.5 left at day 90. Withdrawing then leaves 0. Taking back the full 3 would leave -1.5, and repeating the cycle would drive any memory down.

Which index library (Q9, D39)

Decided: MiniSearch. It is popular without being the most downloaded, has no dependencies, is MIT licensed, ranks by BM25, and can add and remove entries as memories change. It sits behind the MemoryIndex interface, with a contract test and a check that nothing else imports a search library, so changing it later means writing one new implementation.
