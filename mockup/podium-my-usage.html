My usage (#726) View Mode Width

What this mockup proposes

  • A My usage button in the top bar, left of My reporters, on the app's own .btn. The name was chosen on #726 ("Reports" is too close to My reporters, "Activity" already names the activity feed).
  • The page has the Admin report shape: Period and filters, then Spend, Sessions, Failures and Tools, each a panel with a chart, a table and the pager. Every table can be exported as CSV or JSON, and printed.
  • A Harness filter (All, Claude Code, OpenCode) sits with the period, and every export has a harness column. A figure only one harness reports says so under the table (Effort, here).
  • The page says what it is: the .note-line under the filters starts "Only your own sessions". There is no "you versus everyone" figure and no group total, so a share is a share of the person's own total.
  • Rows link to History only for the person's own sessions (Open). Nothing on the page names another person, a reporter id or a group.
  • Not signed in shows how to sign in and no data. Setting off shows a console with no My usage button; the page address then shows the same "not found" a missing page does.
  • Admin > Settings gets one switch row, My usage page. It is drawn Off by default; this is the open question above. An Administrator who opens My usage sees their own figures, not the fleet's.
  • The top bar and banner are what development draws today: the page's own pill (My usage), the connection pill, Fleet, Board, History, Chat and Admin buttons, and the banner's one Wall options pill (#1129) that opens Refresh every, Shortcuts, Theme and Mode. My usage has no button of its own on its own page, as for My reporters.
  • The page reads only. It changes nothing, and the Admin read-notice rule does not apply, because no one reads another person's content.
  • No new class or token. Nothing here asks for a change to a standard.

Not drawn

  • Tool failure rate and tool duration columns (#721), cost per call and the token split (#723) and session time (#722) use the same panel and table pieces as Spend and Sessions here, filtered to the person. They are added as those pages settle; #725's figures are not drawn until it merges.
