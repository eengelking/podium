Chips

A small label for a fact about a session or agent: its model, a skill, a warning. Not for actions. Use a button for those.

Use when

  • Showing a fact that does not change on click.
  • Naming a model: color comes from the model token, never a literal.

Do not

  • Recolor a chip to show status. Use the status mark.
  • Put an action in a chip.

Accessibility

A chip is text, so it needs no role. The model name is the visible text and the full model id is the tooltip. A chip never carries meaning in color alone.
