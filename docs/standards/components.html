KPIs
.area.k.kpi.kpi-cap.kpis.mono.sp.v

Use when

  • Showing a count or total for the whole fleet that a person glances at.
  • Adding a small trend line under a figure (cost, tokens).

Do not

  • Putting an action in a KPI.
  • Showing a figure for one session. Use the card.

Each KPI is plain text in reading order: the label, then the figure, then the caption. Trend lines are drawn marks with a text title.

Use when

  • Showing a session on the wall.
  • Showing a state: running, waiting on you, done, or heartbeat lost.

Do not

  • Putting a second primary action inside the card. The whole card opens the session.
  • Showing status by color alone. The band carries an icon and a word.

The card is one button that opens the session. Remove sits beside it, not inside it, so there is no button within a button.
