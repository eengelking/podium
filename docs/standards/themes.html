Themes

Six palettes, each in light and dark. A theme is a set of values for every color token in tokens.css, picked by data-theme-name and data-theme on the root element. Podium is the default and follows the system until a person picks otherwise.

What a new theme supplies

A value for each of the 35 color tokens on the Tokens page, in a block for each mode it ships, plus its id in the theme list (themes.ts) and in the script in index.html. A test fails if a block lacks a token. A theme with no palette for a mode uses Podium's for that mode.

Contrast

Every theme and mode must pass scripts/theme-contrast.ts, which runs in npm test. Text tokens need 4.5:1 on the page and surface colors. Mark tokens need 3:1, or Podium's own ratio for the same mode when that is lower. The four model colors must differ from each other by at least 0.08 in OKLab distance.
