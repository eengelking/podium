# Admin

Admin is for the person who runs the server.

## Pages

<!-- entries:start -->
- [Getting in](01-getting-in.md): Find out who sees the Admin button and how to open Admin.
- [Getting around](02-getting-around.md): Find the Admin pages in the menu and what each group holds.
- [People page](03-people-page.md): Create a person, copy their token and rotate or revoke it.
- [Groups](04-groups.md): Create groups for arranging the console and put people in them.
- [Reporters](05-reporters.md): Check which machines have reported to the server and filter them by state.
- [Settings](06-settings.md): Turn features on or off for everyone on this server and change its settings.
- [Model prices](07-model-prices.md): Edit the per-model prices that every cost in Podium is worked out from.
- [Security](08-security.md): Decide whether reporters may keep using the admin secret.
- [Certificates](09-certificates.md): View the built-in certificate authority and serving certificate when TLS is on.
- [Data](10-data.md): See what Podium stores, for how long, and what you can remove.
- [Stored activity](11-stored-activity.md): Filter the stored Activity history by session, owner or age and delete what you no longer need.
- [Reporting](12-reporting.md): Report who used Podium, what it cost and what went wrong for a period you pick.
- [Admin log](13-admin-log.md): Read who made each change in Admin, and where it came from.
